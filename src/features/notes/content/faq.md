# 常见问题

## 我的笔记存在哪？

桌面版存在你选的文件夹里，每篇一个 `.md` 文件；浏览器演示库存在内存里，刷新还在，清掉站点数据会重置。

## 为什么有些链接是灰色的？

标题没匹配上就是「未解析链接」——可能是拼写不一致，或者目标笔记还没建。去 [[双向链接与反链]] 看匹配规则。

## 为什么没有文件夹？

因为「卡片盒笔记法」用链接代替分类：先写卡片，再连卡片。目录只是收件箱和归档，不是知识结构本身。

## 数据会丢吗？

桌面版笔记就是磁盘上的 Markdown 文件，用任何编辑器都能打开；保存采用原子写，写一半崩溃不会留下半个文件。浏览器演示库只用于体验，正式使用请用桌面版。
