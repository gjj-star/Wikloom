# 全库关系图（图谱）方案骨架

状态：方案草案，未实现。范围按 Chief 的 2026-10-29 口径：最小版三件事——全库关系图、点击节点跳转、悬浮高亮直接相连；不做拖拽布局参数面板、聚类、时间轴、导出图；**标签筛选暂不做**，等实际使用中有人提再加。

渲染库：**cytoscape.js 确定为主选**（3.34.x，MIT，Canvas 2D，零运行时依赖），**sigma.js 留作备选**（4.0.x，MIT，WebGL，另需 graphology 与布局包），仅在 spike 数字不达标时启用。许可门槛为 MIT / Apache / ISC。本文只定义数据与交互契约，换库只换适配层，不影响其余设计。

## 1. 数据来源：只用现有内存索引，不另建数据源

- 节点：`useNotesStore((state) => state.notes)` 里的每一条笔记，一个节点。`id` 是 frontmatter 里的稳定 id，作为图形与位置缓存的 key。
- 边：对每条笔记的 `content` 调 `src/core/links/wikiLinks.ts:15` 的 `extractWikiLinks`，得到 `[[标题]]` / `[[标题|别名]]`；用标题在 `notes` 里找到目标笔记，构成有向边 `source → target`。
- 缺失链接：`extractWikiLinks` 已跳过围栏代码块与行内代码（`wikiLinks.ts:20-48`）；解析不到目标的链接不画边，只计数。
- 标题解析规则与点击链接一致：大小写不敏感、去首尾空格、取第一个匹配（`src/app/actions.ts:22-31` 的 `openNoteByTitle`）。注意现有反链用大小写敏感匹配（`backlinks.ts:65`），两边本来就不一致；图谱按「点击能得到的结果」走，并在 S1 顺手抽出共用解析函数，不改现有行为。
- 不读取磁盘、不调 Rust、不新增后端命令；`notes` 为空则图空。

### 数据形状（放 `src/core/graph/buildGraph.ts`）

```ts
interface GraphNode { id: string; title: string; tags: string[]; degree: number }
interface GraphEdge { source: string; target: string; linkCount: number }
interface GraphData { nodes: GraphNode[]; edges: GraphEdge[]; missingLinks: number; selfLinks: number }
```

边规则：

| 情况 | 规则 |
| --- | --- |
| `[[标题]]` 命中现有笔记 | 一条有向边 |
| 同一对笔记多条链接 | 合并一条边，`linkCount` 累加（暂不做粗细） |
| 链接到自己（`[[本笔记标题]]`） | 不画边，计入 `selfLinks` |
| 目标不存在（断链） | 不画边，计入 `missingLinks` |
| 两条笔记同名 | 按 `openNoteByTitle` 规则取首个；这是已知的链接身份问题（D03/AC07），不在图谱需求内修，只在备注里标注 |
| 代码块 / 行内代码里的 `[[ ]]` | 不算边（复用现有提取） |

## 2. 界面位置：新增独立路由，不挤三栏

- 路由：`src/app/router.ts` 的 `Route` 加 `"graph"`，`ROUTES`、`routeTitles` 同步；hash `#/graph`。
- 入口：`src/app/Sidebar.tsx` 的「工作区」导航组加一项「图谱」，放在「全部笔记」之后、「标签」之前；`count` 显示**节点数（笔记数）**，边数与断链数放在入口的 `title` 悬浮提示里（`N 篇笔记 · M 条链接 · K 条断链`）。
- 内容：`src/app/Shell.tsx` 里 `route === "graph"` 时渲染全宽的 `GraphPage`，只保留左侧 Sidebar；不进三栏，也就不会压缩笔记列表和正文。
- 空态：无笔记 →「知识库里还没有笔记」；有笔记无链接 →「还没有双向链接：在正文里写 `[[标题]]`，或点断链卡片创建目标」；有断链时附一句「另有 N 条链接指向不存在的笔记」。
- 主题：画布颜色取现有 CSS 变量（`--c-*`），深浅色切换时重绘，不写死颜色。

## 3. 交互契约

| 动作 | 行为 |
| --- | --- |
| 点击节点 | `openNote(node.id)`（`src/app/actions.ts:8`），路由回到笔记页并按现有习惯打开阅读态 |
| 悬浮节点 | 高亮该节点与直接相连的邻居（入边 + 出边），其余节点与边降透明度；移开后恢复 |
| 悬浮边 | 显示 `source → target` 与 `linkCount`；不画箭头，方向只存在数据里 |
| 缩放 / 平移 | 交给渲染库默认能力，不暴露参数面板 |
| 标签筛选 | 暂不做（2026-10-29 定），等实际使用中有人提再加 |

不做：拖拽固定节点后保存布局、聚类、时间轴、导出、节点右键菜单（可直接复用现有右键菜单后续再加）。

## 4. 改名 / 删除 / 编辑后的增量更新

- 触发：`notes` 数组任何变化（新建、编辑正文、rescan、换库）都重算 `GraphData`。图谱只在 `route === "graph"` 时计算，并加 300ms 防抖；进入页面先立即算一次，不等 `notes` 变化；离开页面时清掉 timer，避免白算一次。
- 位置缓存：`Map<noteId, {x, y}>` 存在页面级；重算后：
  - **已存在节点坐标冻结**：直接沿用缓存坐标，重算时不重跑布局迭代（warm start 后不再收敛），只有新节点需要摆放；
  - 新节点放在其首个已存在邻居附近，没有邻居则放视口中心；
  - 消失的 `id` 从缓存删除。
- 这条是验收 4 的前提：图页面内节点只因为用户操作（平移/缩放）移动，不会因重算漂移；跨访问（离开再进）允许重新布局，符合「不做布局持久化」的范围。
- 目前应用内没有改名/删除入口（PRD-STATUS AC07 已记），所以改名/删除来自外部文件 + rescan：rescan 后 `id` 不变、标题变化只影响边，坐标仍保留。
- 渲染库若支持增量增删元素，就用增删；否则整体重建但喂回旧坐标且不再迭代。

## 5. 验收口径

1. 节点数 = 笔记数（孤立笔记也有节点）；边数 = 去重后的可解析 wiki 链接数，日志/角落显示 `missingLinks`、`selfLinks`。
2. 点击任意节点 → 打开对应笔记（阅读态），路由回到笔记页，左侧列表选中正确。
3. 悬浮节点 → 该节点与直接邻居高亮、其他淡化；移开恢复；深/浅色都成立。
4. `notes` 变化后回到图谱，节点/边自动更新，无需重启或手动刷新；**图页面内**已存在节点不因重算漂移（坐标冻结），只有新节点被摆放；跨访问（离开再进）可以重新排布，不承诺位置永久稳定。
5. 空库、有笔记无链接两种空态都有说明；断链数量与实际一致。
6. 规模：1000 节点 / 5000 边（脚本生成）下进入图谱首屏 ≤ 2s（本机基线，实测后写死阈值），缩放/平移/悬浮无明显卡顿（单次交互卡顿 < 100ms），连续操作 1 分钟内存不持续上涨。
7. 离线：断网时图谱可打开，无任何外部请求（Playwright 断言无跨域请求；Tauri 真机复测 WebView2 表现）。
8. 不新增数据源：`git diff` 里不应出现新的磁盘扫描或 Rust command。

## 7. Spike（S3，半天，渲染接入前）

选型结论是 cytoscape.js 主选、sigma.js 备选；「1000 节点 / 5000 边能跑」目前只是推断，不能当依据（参照 L-20261028-01）。S3 用半天把推断变成数字，不达标就换 sigma——数据源与 `GraphData` 不变，只换渲染层。

做法：

- 依赖：`cytoscape@3.34.x`（MIT、零运行时依赖），本地打包，不引 CDN；`package.json` 与 lock 同步提交。
- 数据：用 `buildGraph` 的合成输入造 1000 节点、5000 边（每节点平均 5 条出边，含少量孤立节点与断链），不依赖真实知识库。
- 页面：临时 spike 路由（仅存在 spike 分支，验收完删除，不并入主线），Tauri debug 版（WebView2）里打开；浏览器结果只作对照。
- 测量（每次跑 5 轮，记录中位数 / p95，原始日志存 `audit/graph-spike/`，脱敏后入库）：
  1. 首屏布局耗时：数据就绪 → 首个可交互帧（`requestAnimationFrame` 回调）的 `performance.now()` 差。
  2. hover 高亮延迟：`pointermove` 命中节点 → 邻居 class 应用并完成重绘（下一个 rAF）的时间；重复 30 次取 p95。
  3. 拖拽平移帧率：脚本连续平移 3 秒，统计 rAF 间隔的平均 FPS 与长帧（>50ms）数量。
- 判定：首屏 > 2s 或 hover p95 > 100ms → 换 sigma.js；平移先记录，阈值实测后再定（建议 ≥ 30 FPS 且无明显长帧）。
- 产出：三个数字 + 环境（WebView2 版本、机器大致配置）+ 结论（留在 cytoscape / 切 sigma）写回本文 §7，并据此更新 S4 的适配库。
