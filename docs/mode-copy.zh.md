# 内置模式中文文案

提示词仍用 `plugin-modes.json` 英文原文，此处只改界面文案。

| 模式 ID | 中文名 | 一句说明 |
| --- | --- | --- |
| explain | 概念解释 | 用清晰的结构把概念讲透，适合第一次系统理解。 |
| deep-inquiry | 深度追问 | 拆前提、找反例、权衡取舍，检验一个想法是否站得住。 |
| feynman | 费曼教学 | 用类比和白话讲给外行听，暴露理解里的空洞。 |
| book-summary | 读书摘要 | 按章节提炼脉络、关键要点和可执行清单。 |
| researcher | 主题研究 | 汇总证据、不同观点和未解问题，适合做主题调研。 |
| flashcard | 记忆卡片 | 生成问答卡片，方便间隔复习。 |
| compare | 对比分析 | 把概念、工具或方案并排比较，列出差异和适用场景。 |
| cheatsheet | 速查表 | 压缩成命令、语法和常用模式的快速参考。 |
| socratic | 苏格拉底提问 | 用连续追问带你自己想出答案，而不是直接给结论。 |
| cornell | 康奈尔笔记 | 按线索、笔记、总结三栏整理，方便复习。 |
| glossary | 术语表 | 把相关术语、定义和关系整理成结构化词表。 |
| debate | 多角度辩论 | 让正反双方各自最强地论证，暴露分歧点。 |
| howto | 操作指南 | 给出前置条件、分步骤操作和常见故障排查。 |
| mindmap | 思维导图 | 用层级关系画出一张概念地图。 |
| eli5 | 讲给小白 | 用极简语言解释，假设读者完全没有背景。 |
| timeline | 时间线 | 按时间顺序梳理一个概念或技术的来龙去脉。 |
| devils-advocate | 魔鬼代言人 | 专门挑假设和漏洞，压力测试你的观点。 |
| project-breakdown | 项目拆解 | 把想法拆成阶段、任务和里程碑。 |
| case-study | 案例研究 | 用真实案例复盘决策、结果和可迁移的经验。 |
| question-generator | 复习题 | 围绕主题生成一组复习问题，附答案要点。 |
| active-recall-prep | 主动回忆 | 把解释改写成挖空练习，逼自己回忆关键步骤。 |
| lesson | 单课设计 | 只讲一个最小知识点，配练习、速查卡和原始出处。 |
| general-deep-article | 深度长文 | 面向任意主题写一篇有证据、有细节的长文。 |
| further-reading | 延伸阅读 | 从入门到进阶整理书、视频、课程和文章。 |
